# Veylola AI

Veylola AI is a modern AI assistant with a clean chat interface and a server-side AI API connection.

## Features
- Responsive Veylola AI chat UI
- Conversation history during a session
- New chat button
- Server-side API key protection
- Ready for Vercel deployment

## Deploy
1. Import this GitHub repository into Vercel.
2. Add an environment variable named `OPENAI_API_KEY` with your API key.
3. Optionally set `OPENAI_MODEL` (default: `gpt-5-mini`).
4. Deploy and open the generated Vercel URL.

Never put an API key directly in `app.js` or `index.html`.
